# SulitScan SEO and AdSense Readiness Audit — November 16, 2026

## Outcome

SulitScan already has the main technical and trust foundations expected of an indexable affiliate editorial site. The audit did not find a reason to redesign the site or add more ad code. It did find one material on-site trust problem: seven indexable category guides still promoted Temu after the affiliate catalog had been retired. That copy and the category search descriptions were corrected in this release.

Five new buyer guides were also added because they fill distinct search and task gaps, not merely to make the site look active. Google explicitly recommends people-first, useful content and warns against publishing many pages only to appear fresh. More articles do not guarantee AdSense approval.

The remaining AdSense blocker is external configuration: the production site still needs the owner's real AdSense publisher ID. Before this release, the live homepage had no `google-adsense-account` meta tag and `/ads.txt` returned the site's deliberate “not configured” comment.

## Scope and evidence

The audit covered:

- the production homepage, robots file, sitemap, categories, Shopee store route, recent article, and `/ads.txt`;
- the current Next.js route metadata, structured data, sitemap, article registry, category guidance, partner catalog, policy pages, and AdSense controls;
- internal-link, affiliate-link, content-registry, sitemap, compliance, type, lint, and production-build checks;
- current Google Search and AdSense guidance; and
- current first-party DTI and Shopee sources used by the new guides.

Pre-release production evidence:

- `https://sulitscan.com/` returned 200, index/follow, and a self-canonical URL.
- `https://sulitscan.com/robots.txt` returned 200, allowed public crawling, excluded `/api`, and named the sitemap.
- `https://sulitscan.com/sitemap.xml` returned 200 with 105 URLs: 64 blog posts and 18 active deal routes among the permanent pages.
- Tested category, store, and October article routes returned 200 with index/follow and self-canonical metadata.
- Live `/ads.txt` stated that AdSense was not configured; the homepage did not contain the AdSense account meta tag.
- Google's PageSpeed Insights API returned HTTP 429 during this audit, so no unsupported performance score is recorded here. Local production build and browser checks remain part of release verification.

- BlogPosting, FAQ, breadcrumb, item-list, and product structured data where appropriate.
- About, contact, editorial policy, affiliate disclosure, privacy policy, cookie policy, corrections path, and article trust panels.

## AdSense owner action — do this before requesting review

The application code is ready for verification, but the repository cannot invent or retrieve the owner's publisher ID.

1. In AdSense, add `sulitscan.com` under Sites and copy the real ID in the form `ca-pub-0000000000000000`.
2. In Vercel, add `NEXT_PUBLIC_ADSENSE_CLIENT_ID` with that real ID for Production, Preview, and Development.
3. Keep `NEXT_PUBLIC_ADSENSE_ADS_ENABLED` unset or set to `false` during ownership verification and policy review.
4. Redeploy.
5. Confirm the production homepage contains `<meta name="google-adsense-account" content="ca-pub-...">`.
6. Confirm `https://sulitscan.com/ads.txt` contains `google.com, pub-..., DIRECT, f08c47fec0942fa0` with the same 16 digits.
7. In AdSense, verify the site and request review. Do not remove and re-add the site merely because review takes time; Google says reviews may take several days and sometimes two to four weeks.
8. Only after the AdSense site status is Ready, configure the required Google-certified consent management platform, enable a low ad load or Auto ads in AdSense, set `NEXT_PUBLIC_ADSENSE_ADS_ENABLED=true` in Production, and redeploy.

Google alone makes the approval decision. Common “needs attention” causes include missing connection code, an unreachable site, insufficient unique value, navigation problems, or policy issues. The live [Google site-status guidance](https://support.google.com/adsense/answer/12170222), [site connection steps](https://support.google.com/adsense/answer/7584263), and [not-ready troubleshooting](https://support.google.com/adsense/answer/12176698) take precedence over this checklist.

## 28-day measurement plan

Record a baseline on the deployment date, then review at 14 and 28 days:

- Google Search Console impressions, clicks, CTR, and average position for each new page;
- the queries producing impressions, including terms the page does not yet answer clearly;
- indexed status and canonical selection for the five new URLs;
- Vercel pageviews and referrers for each guide;
- outbound affiliate clicks or partner conversions where the network provides reliable reporting; and
- Core Web Vitals for the blog route after the five images are cached.

Do not rewrite a page based on a few days of zero clicks. First check indexing and impressions. When a page receives impressions but weak CTR, test the title and description against the actual query. When it receives no relevant impressions after a reasonable observation period, reassess search intent, internal links, originality, and competition before publishing a near-duplicate article.
